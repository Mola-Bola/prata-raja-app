# Prata Raja UI/UX audit (v0.4.49, main 2e16331), 390x844 Playwright, 15 Oct

Method: `git archive main` copy, web export with wall off (dummy Supabase; the build also needs `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` and `expo export -c`, the brief's env var name was wrong), served on :8297 (port 8199 belongs to another agent). Fresh save and a seeded v3 save (Kannan 11, 5,000 coins, 30 of each material, all unlock flags). Shots in `shots/` (contact sheets `s3..s12.png`). Font sizes and contrast are computed from the live DOM plus the CSS tokens. Peer notes (hub seams, GO overlap, duplicate headers, tiffin dead slots, stale copy, two levels) are not repeated except where I add numbers. Most of those are still true on this build.

## 1. Flow map

```
Title (Intro | Start/Continue) -> [new: Prologue 6 panels, Skip] -> Run 1 -> Results -> Hub
Hub: walk into station = panel (bottom sheet, x closes). GO = run (new player) or "Out to the street" chooser (once Hawker Night is unlocked)
Run (free HUD): Pause -> {Build & stats, Resume, Restart, End run, Tell Kannan, 3 toggles, Analytics}. End/die -> Results
Results: Daydream again | Back to stall (=hub) | Tell Kannan
Hub cog -> Settings sheet -> Story (replay) | Old stall menu | Kitchen | (Tune, dev)
Old stall: second full hub (photo room) -> "New hub" | Test Kitchen | sheets. Kitchen: "Stall" exits to OLD stall, not the hub.
```

Dead ends and double-backs
- **Old stall menu is a complete second hub** (Calendar, Training, Recipe book, Gear, Tip jar, Chests, Dip collection, Forge, Chef's Special, spec points, Start). Every sheet duplicates a hub station. It is reached from Settings, with a "New hub" button that floats over its own bottom bar (`41-oldstall`). Pure double-back; delete or hide.
- **Kitchen opens with the "Set the tawa" sheet over everything**; its exit button is labelled "Stall" and, until the sheet is closed, the canvas intercepts the click (Playwright could not click it). Exit lands in the old stall (3 taps from the hub, not 1).
- **GO is two different things**: starts a run for a new player, opens a chooser once Hawker Night unlocks. Same pill, different result; the chooser is a panel with no run info.
- **"Back to stall" says stall, the destination is the hub.** "Daydream again" is the only primary; no "what changed" CTA (spend points, open chest).
- **No next-step cue for a new player.** After run 1 the hub shows 8 labelled props, `★ 0`, 0 coins, and nothing pointing anywhere. Gear shows a padlock plus "Unlocks: Play your first daydream" right after the player did exactly that (the run was "too short", so it did not count, but the screen does not say so). Tawa: "Unlocks: Beat the Burger Baron." (the player has never heard of one). Kopi uncle lists four meals with "(have 0)" costs the player cannot meet.
- **Level-ups give no moment in the free run**: the HUD number climbs 11 -> 14 in 60 s with a ring FX only; the card modal (`LevelUp` in GameUi.tsx) never appeared in two non-bot runs. Fine if intended, but then "Rotis/Dips/Passives" in the pause build screen is the only place a player learns what changed.
- **Panels cover the very stations you walk to**: a panel is 45-65% of the screen, the camera pans, GO sits on top of its bottom-right (every shot `11-*`). The only exit is the 44 px x (or walk away). Esc works on web only.
- Free-run pause menu: 9 buttons + 4 switches in one card (`31-pause`); "End run" (testid `ui-quit`) lands on a results screen scolding the player ("stop daydreaming!") for ending on purpose.
- Revive: no UI exists (only a `revives` stat and an FX). Boss: banner plus a top bar, readable.

## 2. Visual system inconsistencies

**Two UI systems.** The Paper theme (`src/ui/brand.ts`: leaf green `#167A55`, ink-blue text, 15-30 px scale, `BigButton`) is the stated baseline. The game never uses it: all of `src/game/ui/*.css` (2,728 lines) runs on its own tokens (`--cream #FFF4E0, --orange #F28C28, --edge #A9764A`, `--fs-*`), and the hub GO is a green leaf PNG that matches neither orange nor Paper green. So the "one `go` per sheet" rule is broken at the root: orange `gu-btn--primary` (cream/brown), green leaf GO, brass Pause, orange round Dodge.

**Type sizes**
- Computed (screens walked): 11, 12, 13, 14, 15, 16, 17.55, 18, 19, 20, 21, 22, 24, 26, 28, 30, 32, 44 = **18 sizes**. Declared in CSS: 20 distinct px values (11 to 60) vs. 5 `--fs-*` tokens that cover only a fraction (15 px is declared 19 times, 16 px 10 times, raw).
- Fonts: Fredoka (headings/buttons) and Nunito (body); weights 400/600/700/800/900 all in use; the `.gu-*` classes hard-code `font: 600 20px/1 Fredoka`.
- Sub-13 px in use: HUD "L1/L2" socket badges 11 px, "God" 11 px, tiffin "Start/Slot 2/Slot 3" 11 px, HUD distance "1194 m to boss" 12 px, boss label 12 px, dip tile names 12 px (7 tiles, Dip shelf), find card quote 12 px.

**Buttons: about 20 distinct styles** (computed radius/size/shape): `gu-btn` (18 r, 15/19 px, two heights 40 and 52), `gu-btn--primary`, `gu-btn--cream`, `gu-btn--wide`, `hb-go` (art), `hb-cog` (round art), `hb-tab` (999 r pill, 40 high), `fb-chip` (pill, 44), `fg-chip`, `fr-chip`, `gb-chip`, `gu-chip`, `gu-build-chip`, `gu-switch`, `fb-switch`, `sh-tile` (14 r), `sh-chapter` (cards 254 vs 301 wide, ragged), `sh-prop/sh-label` (old stall), `spec-node` (3 shapes, 44-56), `kt-disclosure`, `gb-info` (32 px), `fb-x` (48 r16 x) vs hub x (44 r18 x) vs "Close" text buttons (75x44). "Known recipe" is a full-width button that does nothing.
- Radii in CSS: 999, 50%, 14, 18, 16, 12, 10, 26, 8, 5, 24, 22, 3, 20 = 14 values.
- Touch targets under 44: hub tabs 40, Tell Kannan 40, info (i) 32.
- Hex literals in game CSS: 19 distinct, not from brand.ts (CLAUDE.md says none in components). Inline hex in GameUi.tsx (`#E8702A` tuned badge, `#fff` God label).

**Icons are mixed**: painted PNG atlas icons (panel headers: tawa, katori, anvil, sack, chalkboard, cup) for only 6 of 9 panels (Spec board, Settings, Exit have none); unicode glyphs for game meaning (`★ ◆ ● ✿` spec nodes and the spec counter, `⏱ ↩ ⓘ` in the build screen); emoji (`🔥 📉` traits, `🔥` calendar and Chests headers); a painted lock; a text "x" close. Four icon vocabularies on one screen (`s6`, Chests: emoji header over painted tabs).

**Panels/colours**: sheets are cream with 3 px brown edge (good, consistent) but: Curry pot header is a mid-brown banner with cream text 4.0:1; the Gear/Wear panel has a coin balance pill, other panels none; Dip tiles are 76 px wide in Katori but 112 px in Curry pot (same items, two grids); empty katori are grey ovals (neither cream nor brown). Header: icon + title in 6 panels, title only in 3, duplicated title inside the content in Kopi uncle ("Kopi uncle" twice + x + "Close") and Spec ("Spec board", "Spec", x and "Close").

## 4. Proposed UI system

**Type scale (5 sizes, Fredoka for display, Nunito for body)**
| token | px | use |
|---|---|---|
| `t-hero` | 30 / Fredoka 700 | title Start, results headline number, level-up |
| `t-title` | 22 / Fredoka 600 | sheet titles, results line |
| `t-btn` | 18 / Fredoka 600 | all button labels, HUD numbers |
| `t-body` | 15 / Nunito 700 | everything readable |
| `t-cap` | 13 / Nunito 700 | captions, pills, tile names, HUD sub-line. Nothing below 13 |

**Three button tiers** (one family: 3 px edge, lip shadow, 18 r, 52 high, 44 min)
1. **Go**: orange fill, ink text, lip. One per screen or sheet footer. Replaces the leaf GO png (keep the leaf as art on the hub pill only if the hub pill is the sole `go`).
2. **Plain**: cream fill, ink text, brown edge. Secondary actions (Back, Reroll, Swap).
3. **Chip**: 999 r, 40-44 high, tabs/filters/toggles (merge `hb-tab`, `fb-chip`, `gu-chip`, `gu-switch`). Selected = orange fill.
Round game buttons (Dodge, Pause, close x) are one 44 or 56 px "round" variant of tier 2 or 1; Dodge text ink on orange (5.9:1) not cream.

**Panel/sheet anatomy**: header (icon 28 px painted, title `t-title`, one 44 px x at the right, no second title inside); body (scrolls, max 60% of the height, tabs as chips under the header, at most 2 levels); footer (sticky: the one `go` action for the panel when it has one, otherwise the sheet's Close). The hub GO hides while a panel is open (the footer takes its place), which removes the overlap everywhere. Sheet height fixed per station, not per content; the camera pan stays.

**Iconography rule**: painted atlas icons only for things the player owns or does (stations, materials, dips, gear, coins, chests); one glyph set for UI controls (x, lock, info, back, star as a painted icon); no emoji, no unicode shapes as icons. The spec nodes get painted shapes (small, notable, keystone) with a legend row.

**Motion**: press 90 ms ease-out (exists); sheet in 220 ms `cubic-bezier(.2,.8,.2,1)` (exists), out 140 ms; list items 30 ms stagger max 5 items; reward counts 600 ms ease-out; loop animations (shine, glow) only on the one next-step target, none elsewhere; `prefers-reduced-motion` drops everything but fades. No motion longer than 300 ms on the path from GO to the first enemy.

**Target flow and what each screen must show**
- **Title**: logo, one Start/Continue, tiny version. Intro and the caption pill move to Settings > Story. Continue shows "Best 1,200 m" and chapter.
- **Hub**: top strip = Kannan level ring + coins (+ points only when > 0). One pulsing target for the player's next step (new: the stove; later: an unopened chest, unspent points). Stations labelled on the prop, 13 px. GO always visible bottom right; hidden while a panel is open.
- **Run**: top row = level ring, HP bar, pause, coins; distance in a thin bar (14 px), no truncated chapter name (use the icon or "Ch 1"). Dodge bottom right. One-line toasts for finds (no Swap popup mid-run; swap lives in the pause menu).
- **Pause**: Resume (go), Build & stats, Settings (3 switches in a sub-sheet), End run (plain, confirm), Tell Kannan as the tab. Four buttons, not nine.
- **Results**: headline (1 line), metres hero number, 3 rewards max (coins, XP bar, loot chip), "Next: <one thing>" line, buttons Daydream again (go) and Back (plain). Tips and simmer detail go into a "Details" expander.
- **Hub again**: a "new" dot on the stations that changed (chest, points).
