# Counter attack windows — ledger 61 prototype

Normal melee now has a per-enemy counter-breach cycle: **0.30s preparation, 0.20s strike, 0.50s recovery**. First arrival changes to the existing `attack` targeting state and starts a fresh clock at zero. This stays a counter threat: lateral movement alone does not dodge contact. The readable preparation allows killing, knocking back or controlling the attacker under the existing geometry.

`src/core/contactAttack.ts` shares the cycle and current phase between core and renderer. Strike damage uses the exact overlap of elapsed time with every strike window crossed, multiplied by five times the previous contact DPS. Complete uninterrupted one-second cycles therefore preserve the old damage budget, including elite/incoming-damage multipliers and stacked attackers. Short, interrupted or lethal encounters can differ; this is the intended hypothesis and still requires balance measurement. There is no attacker cap, RNG call or new hit geometry.

`Enemy.contactClock` is optional and separate from `e.t` (dash/summoner clocks). Knockback beyond the existing reach slack clears the clock and stale attack state **before** the disabled-state return; coming back starts a full preparation. Freeze/stun pause attack time. An expiry inside a step advances only the unblocked remainder, retaining partition consistency. Ordinary movement and special behavior retain their existing timers. Boss, shooter with ranged data, healer, exploder and thief behavior remain outside this clock. A shooter missing its ranged data uses its existing walk fallback with the new normal cycle.

The actor's preparation, lunge and recovery follow its own core clock. Ordinary actors ignore aggregate `counterHit` animation triggers and no longer derive attacks from shared `contactT`; other event animations remain. The existing compact `!` warning grows on amber during preparation, turns strong red during strike and disappears during recovery, leaving only a dim counter-edge ground cue. Knockback/control/death clear warnings. Reduced motion keeps fixed-size truthful amber/red cues and suppresses the added attack displacement. Existing palette/art are reused; no debug labels, dependencies or Expo/React Native APIs were added. Glyph scaling and color-change guards avoid per-frame font rasterization.
